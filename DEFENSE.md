## 7.1

Команды /make_ai_review и /make_other_ai_review выбирают разные модели. Успешный результат и ID PR сохраняются в Data Table. Повтор основной команды прекращается на Skip Duplicate. Diff разбивается на блоки, комментарии привязываются к изменённым строкам path/side/line. В PR и таблице есть результаты обеих моделей; отдельного сохранённого Execution второй модели среди семи скриншотов нет. При живой защите открыть существующий Execution второй ветки в n8n; не удалять таблицу ради повторного запуска.

## 7.2

Классификатор принимает title/body и возвращает type/confidence через Sub-workflow. При confidence < 0.8 или unknown назначается needs-triage без комментария, иначе Switch выбирает bug/task/feature. Отчёт запускается по cron 0 9 * * MON; четыре запроса получают все Issues, bug, task и feature за прошедшие семь суток. Данные группируются по типу и автору и отправляются HTML-письмом через Gmail. Снимки сохраняются в Data Table; Δ вычисляет код, AI объясняет статистику в письме. Тестовая база прошлой недели помечена simulated=true.

В JSON отчётов явно задан Europe/Moscow. Настройка локального файла не меняет опубликованный экземпляр: при защите открыть Schedule Trigger и Workflow Settings, проверить timezone и публикацию только расширенного отчёта. Условие разрешает ручной запуск без ожидания понедельника.

## 8

AI-прототип v0 и рабочий React-интерфейс используют shadcn/ui на Base UI и общую тему. Интерфейс обращается к настоящему webhook n8n. Для демонстрации: alp → успех, GA → Gamma/Omega, @@@ → валидация, zzz → пусто, замедление сети → загрузка и блокировка повторов, Offline → ошибка → восстановление сети → повтор; затем мобильная ширина и клавиатура. Сетевую ошибку и мобильный экран показать живьём: отдельных снимков нет. Сохранены шесть скриншотов успеха, данных n8n, валидации, пустого результата и загрузки.

Из cmd в корне репозитория:

```cmd
powershell -NoProfile -File .\defense.ps1 setup
powershell -NoProfile -File .\defense.ps1 dev
```

В другом окне cmd:

```cmd
powershell -NoProfile -File .\defense.ps1 test
powershell -NoProfile -File .\defense.ps1 quality
powershell -NoProfile -File .\defense.ps1 build
```

Сохранённый результат: 25 Vitest и 4 Playwright прошли; сборка успешна. MSW и page.route подменяют HTTP-ответы успеха, пустых данных, задержки и ошибок. Проверка качества намеренно скрывает alert: тесты падают, после восстановления проходят; SHA исходника до и после совпадает. Эксперимент запускается отдельно от остальных тестов.
