# Homework 7–8: валидатор строки и фильтр списка

Продолжение проекта из практики 5: пользователь вводит строку, приложение
проверяет её и фильтрует список без учёта регистра. Пустая строка возвращает
весь список; неподходящий ввод показывает ошибку; кнопка сброса очищает фильтр.

## Запуск

Из корня репозитория в PowerShell (Python 3):

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory string-validator/ui
```

Если команда python указывает на неработающий ярлык Windows, используй установленный Python по полному пути:

```powershell
& "$env:LOCALAPPDATA\Python\bin\python.exe" -m http.server 8000 --bind 127.0.0.1 --directory string-validator/ui
```

Открыть http://127.0.0.1:8000/ . Не открывать index.html через file://:
приложение загружает items.json через fetch.

## Проверки

Node.js без установки пакетов:

```powershell
node --test string-validator/tests/test_filter.cjs
```

Исходные браузерные проверки: http://127.0.0.1:8000/index_test.html
Они используют настоящую логику и браузерный DOM, но ещё не являются полным
набором клиентских тестов по требованиям ДЗ 8.
