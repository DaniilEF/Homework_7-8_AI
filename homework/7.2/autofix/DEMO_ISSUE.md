# [Учебный дефект] Поиск не учитывает регистр заглавных букв в запросе

Это контролируемый учебный дефект для демонстрации автоматического исправления через n8n. Он специально внесён в `string-validator/ui/app.js`; это не обнаруженный пользовательский инцидент.

## Шаги воспроизведения

1. Вызвать `filterItems` со строкой `GA`.
2. Передать список элементов с именами `Alpha`, `Beta`, `Gamma`, `Delta`, `Omega`.

Фактический результат: пустой массив `[]`.

Ожидаемый результат: элементы `Gamma` и `Omega`, поскольку поиск должен выполняться по подстроке без учёта регистра.

Контрольный пример: запрос `ga` уже возвращает `Gamma` и `Omega`.

## Ограничения исправления

Сохранить прежний контракт: пустой запрос возвращает исходный список; разрешены латинские буквы, цифры и все JS whitespace; максимум 40 символов; без trim; исходный массив не изменяется. Исправление должно включать регрессионный пример для `GA`.

Для ручной проверки из корня репозитория: `node --test string-validator/tests/test_filter.cjs`. До исправления ожидается падение `case-insensitive substring filtering`, после исправления все тесты должны пройти.
