# Результаты проверки ДЗ 8

Запуски выполнены 18 ноября 2026 года на Windows, Node.js 24 и Google Chrome.

| Файл | Что подтверждает |
|---|---|
| `client-tests.log` | Полный запуск: 25 Vitest-проверок и 4 Playwright-проверки прошли |
| `quality-check.log` | Повторный запуск test:quality: ожидаемая поломка обнаружена, исходник восстановлен |
| `build.log` | Проверка TypeScript, включая тесты, и production-сборка Vite прошли |
| `mutation-broken.log` | После намеренного скрытия ошибки три проверки неверного ввода упали из-за отсутствия alert |
| `mutation-restored.log` | После восстановления те же три проверки прошли; остальные тесты при этом целенаправленно отфильтрованы |
| `mutation-result.json` | Коды завершения и одинаковый SHA-256 исходного и восстановленного SearchForm |

Падение в `mutation-broken.log` ожидаемое и относится только к временному эксперименту. Успешный полный клиентский набор подтверждает `client-tests.log`; эксперимент выполнен отдельно, после него исходник восстановлен и проверен по SHA-256.

В клиентском наборе ответы сервера подменяются MSW или Playwright route. Эти логи не выдают подменённые ответы за настоящий запуск n8n. Живая интеграция проверялась отдельно (`frontend/smoke-live.mjs`).

Настройки, тестовые данные, команды запуска и соответствие критериям описаны в [testing.md](../testing.md).
