# Прототип валидатора из v0

Сохранён 18 ноября 2026 года. Это образец интерфейса для последующей реализации ДЗ 8, а не готовая интеграция с n8n.

- `v0-export.zip` — неизменённый архив `project (1).zip`, предоставленный пользователем после исправлений.
- `v0/` — распакованные исходники этого экспорта, без кеша `tsconfig.tsbuildinfo`.
- `screenshots/v0-first-review.png` — скриншот предыдущего экспорта `project.zip`, до исправлений. Не является снимком обновлённой версии.
- `../design.md` — описание вклада AI, промптов и исправлений.
- `../spec.md` — требования к будущему рабочему интерфейсу.

## Запуск экспорта

Из каталога `homework/8/prototype/v0`:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Открыть адрес, который выведет dev-сервер (обычно `http://localhost:3000`). Версия менеджера пакетов указана в `package.json`. Экспорт использует Next.js, React, TypeScript, Tailwind CSS и shadcn/ui. Установка зависимостей и сборка при сохранении экспорта не выполнялись.

## Просмотр

Проверить `alp` → Alpha, `GA` → Gamma и Omega, `zzz` → отсутствие совпадений, `@@@` → ошибку. Пустой запрос возвращает пять элементов. Отправка работает по кнопке или Enter; сброс очищает поле и возвращает фокус.

Панель «Демонстрация состояний» предназначена для просмотра прототипа. Переключатель сбоя имитирует ошибку следующего запроса; повтор затем может завершиться успешно. Ручное демо загрузки сохраняется до выбора другого состояния.

В `lib/mock-api.ts` ответ имитируется таймером 900 мс: настоящий HTTP-запрос не выполняется. Вывод строки `GET /api/items?...` в демопанели не подтверждает работу API. Рабочая версия будет обращаться к webhook n8n; подмена ответов останется в тестах.

Публичная ссылка v0 пользователем не предоставлена; для проверки сохранён экспорт исходников. Клиентские автотесты, сборка и проверка в браузере относятся к следующим этапам.
